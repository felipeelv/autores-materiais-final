# História

Pasta exclusiva para os autores, modelos, memórias e validadores de História do Ensino Médio.

O padrão editorial está em `AUTOR.md`: prosa direta, raciocínio histórico explícito, uma frase por box e preferência por 145–175 palavras por aula.

Há um capítulo-modelo validado para cada série em `modelos/`. Eles foram formalizados como os Capítulos 1 oficiais.

O 3º bimestre está concluído: **12 capítulos · 54 aulas**, salvos em [Segundo Semestre/História](https://drive.google.com/drive/folders/1Na_5uJ539RgBEUJmy1r73SmAy4kGe3M_).

Estado detalhado:

- decisões editoriais: `_MEMORIA.md`;
- produção: `Acompanhamento de produção.md`;
- validação: `python3 Historia/validar-capitulo.py <arquivo.md> --disciplina historia`.
