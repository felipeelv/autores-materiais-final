# Geografia

Pasta exclusiva para os autores, modelos, memórias e validadores de Geografia do Ensino Médio.

Os modelos aprovados estão em `modelos/`, com um arquivo para cada série. Todos seguem o padrão conciso vigente.

O 3º bimestre está concluído: **12 capítulos e 54 aulas**, validados e salvos na pasta oficial [Segundo Semestre/Geografia](https://drive.google.com/drive/folders/1bIep9JGBQaZbhNHxYqe-Fp1He_syo26r).

O padrão vigente está em `AUTOR.md`; o histórico das decisões fica em `_MEMORIA.md`; o estado da entrega está em `Acompanhamento de produção.md`.
